# Reminder Proof design system

`tokens.css` is the executable color, type, spacing, radius, and motion contract. `component-inventory.json` is the 20-component implementation queue with required states and first milestone.

The canonical rationale and screen behavior live in [`.factory/design.md`](../../.factory/design.md). M1 should implement components in `apps/web/src/lib/components/` and keep these contracts synchronized. Do not add a generic component framework or runtime font CDN.
